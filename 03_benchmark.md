# 3. Бенчмаркинг конкурентов — PRism

> **Цель:** зафиксировать целевую аудиторию и проблему, сопоставить прямых и косвенных конкурентов, определить значимые параметры рынка и их значения, вывести средние ориентиры по метрикам и на этой основе задать стандарты для PRism.

---

## 3.1 Целевая аудитория и проблема

**Аудитория.** Команды разработки от **3 до 50 человек**, активно использующие GitHub и практикующие pull request review; технические лиды и senior-инженеры, отвечающие за качество кодовой базы; стартапы и продуктовые компании без выделенного architect, но с растущим техническим долгом. Первичный языковой фокус продукта — **Java** (MVP), далее расширение по стеку из бизнес-дока.

**Проблема.** Code review неравномерен и часто **поверхностен**: в диффе не видны архитектурные нарушения, N+1 и race conditions в связке с остальной кодовой базой; линтеры не закрывают смысловой слой; очередь PR растёт быстрее, чем senior успевают ревьюить. Команда теряет время на рутинные замечания и **не получает раннего сигнала** по антипаттернам уровня SOLID / coupling / security-мисконфигураций в привычном UX (inline-комментарии к строке PR).

Именно эту щель закрывает PRism; бенчмаркинг нужен, чтобы понять **планку ожиданий** по интеграции, скорости, шуму и цене у ближайших по сценарию решений.

---

## 3.2 Прямые и косвенные конкуренты

| # | Конкурент | Тип | Почему в выборке |
|---|-----------|-----|------------------|
| 1 | **CodeRabbit** | Прямой | AI review PR с inline-комментариями на GitHub/GitLab; ближайший UX-сценарий. Крупная установленная база (миллионы репозиториев и PR в маркетинге). |
| 2 | **Codacy** | Прямой | Автоматизированный review на PR, AI Reviewer, confidence / FP triage, широкий DevSecOps-стек на одной платформе. |
| 3 | **Snyk Code** | Косвенный | Не конкурирует по SOLID / архитектурным антипаттернам, но задаёт планку по **security SAST**, точности и формату PR-комментариев для класса уязвимостей. |

Интеграционный путь у всех трёх — **GitHub App / webhook**, как у целевого MVP PRism. CodeRabbit и Codacy — главные прямые аналоги по продуктовому обещанию; Snyk — эталон по security-измерениям и enterprise-цене.

## 3.3 Сравнительная информация по конкурентам

### CodeRabbit

**Ссылки:** [coderabbit.ai](https://www.coderabbit.ai) · [docs.coderabbit.ai](https://docs.coderabbit.ai/management/plans) · [G2](https://www.g2.com/products/coderabbit/pricing)

**Позиционирование:** ускорение code review через контекстные AI-комментарии к PR за минуты; не замена человека, а усиление.

**Сильные стороны:** inline-комментарии, walkthrough и диаграммы к PR, one-click fixes, обучение на dismiss-ах, YAML-конфиг, агрегация множества линтеров/SAST с LLM-фильтрацией, SOC 2 Type II, несколько Git-платформ и VS Code.

**Цены (ориентиры):** Free ($0, лимиты) · Pro **$24/dev/мес** (annual) · Pro+ $48 · Enterprise от ~$15k/мес.

**Отзывы:** хвалят скорость, саммари, autofix, онбординг; критикуют шум на старте, слабое понимание бизнес-логики и cross-module, поддержку.

---

### Codacy

**Ссылки:** [codacy.com](https://www.codacy.com) · [pricing](https://www.codacy.com/pricing) · [G2](https://www.g2.com/products/codacy/reviews)

**Позиционирование:** DevSecOps-платформа: качество и security для AI- и человеческого кода; упор на compliance и enterprise SDLC.

**Сильные стороны:** AI Reviewer (Gemini, GitHub), confidence / FP triage, `review.md` для кастомизации, SAST+SCA+DAST+secrets+SBOM, AI Guardrails для агентов, IDE-плагины.

**Цены:** OSS $0 · Pro **$15/dev/мес** (annual) · Business custom (AI Reviewer и расширенный пакет).

**Отзывы:** хвалят охват языков, security dashboard, онбординг; критикуют цену для малых команд, привязку AI Reviewer к GitHub, ручной разбор FP.

---

### Snyk Code

**Ссылки:** [snyk.io](https://snyk.io) · [plans](https://snyk.io/plans/) · [Capterra](https://www.capterra.com/p/172252/Snyk/)

**Позиционирование:** developer-first SAST с AI; continuous defense для кода, в т.ч. сгенерированного LLM.

**Сильные стороны:** data-flow анализ, PR blocking на high/critical, inline-комментарии с severity и fix, связка с SCA/контейнерами/IaC; в материалах встречается оценка **~85% accuracy при ~8% FP** (SAST evaluation study 2024 — ориентир, не юридическая гарантия).

**Цены:** Free с лимитами · Ignite (Team) **~$105/dev/мес** · Business/Enterprise custom.

**Отзывы:** хвалят точность security, data-flow, фиксы, поддержку; критикуют высокую цену, сравнение SAST vs сильного SCA, UI.

## 3.4 Значимые параметры продукта (для сравнения)

Параметры отобраны так, чтобы они **влияют на закупку и adoption**: видны в маркетинге, отзывах или публичных обещаниях и позволяют сопоставить PRism с рынком.

| Параметр | Смысл |
|----------|--------|
| **Позиционирование («что говорит о себе»)** | Одна формулировка главного обещания (скорость vs качество vs security). |
| **Цена / модель** | Вход на платный tier: freemium, подписка per seat, минимальная ставка $/dev/мес где публична. |
| **Что хвалят / что критикуют** | Повторяющиеся темы в G2/Capterra и доках (качественный сигнал). |
| **Время (P95)** | Ориентир задержки от события PR до появления inline-результатов: у конкурентов в материалах — **минуты**; используем диапазоны из п. 3.3 и середину диапазона как точку для усреднения. |
| **Точность** | Публикуемый или маркетинговый ориентир по «полезности» детектов / accuracy; где нет отчёта — середина заявленного диапазона из дока. |
| **Мин. оплата ($/dev/мес)** | Нижняя публичная ставка платного per-seat плана (annual где указано). |
| **Число шагов онбординга** | Оценочное число шагов до первого автоматического комментария на PR (GitHub App: установка → выбор org/repo → политика доступа); **оценка** для сопоставимости, не аудит UI. |

Дополнительно для roadmap PRism (не в итоговой таблице-референсе, но важно для продукта): интеграции Git-платформ, наличие confidence в UI, глубина security vs архитектура, OSS tier — см. раздел 3.7.

## 3.5 Значения параметров у конкурентов и средние по рынку

**Время (мин, P95, оценка середины диапазона):** CodeRabbit **2,5** (диапазон ~2–3), Codacy **2,0** (~1–3), Snyk Code **3,5** (~2–5).

**Точность (%):** CodeRabbit **87,5** (середина маркетингового ~85–90%), Codacy **88**, Snyk Code **85** (публичный ориентир исследования).

**Мин. $/dev/мес (paid):** 24 · 15 · 105.

**Шаги онбординга (оценка):** CodeRabbit **4**, Codacy **5**, Snyk **6** (сложнее продуктовый контур и политики).

**Средние по трём конкурентам (бенчмарк рынка для числовых колонок):**

- время: (2,5 + 2,0 + 3,5) / 3 = **2,7 мин**;
- точность: (87,5 + 88 + 85) / 3 ≈ **86,8%**;
- мин. $/dev: (24 + 15 + 105) / 3 = **48 $/dev/мес**;
- число шагов: (4 + 5 + 6) / 3 = **5,0**.

Эти средние — **не норматив для PRism**, а ориентир «центр масс» выбранных аналогов; целевые значения PRism задаются отдельно (ниже).

## 3.6 Анализ: table stakes и дифференциаторы

### Table stakes — без этого рынок не воспринимает продукт

1. Автозапуск по webhook на `pull_request`.
2. Inline-комментарии к строкам диффа.
3. GitHub App с низким трением установки.
4. Объяснение проблемы и совет по исправлению, а не «есть ошибка».
5. Механизм снижения шума: порог уверенности, FP triage или обучение на feedback.
6. Политика **zero training on customer code** (или эквивалентная формулировка) для enterprise-доверия.

### Дифференциаторы PRism относительно бенчмарка

| Дифференциатор | Почему у конкурентов слабее |
|----------------|----------------------------|
| Классы **SOLID / N+1 / race / coupling** | CodeRabbit и Codacy — generalist; Snyk — security, не архитектура приложения. |
| **ClassifierDecides / LLMFormulates** + видимый confidence | Снижение галлюцинаций; у Codacy triage есть, но акцент не на архитектурных классах PRism. |
| **RAG по кодовой базе** (пост-MVP) | У конкурентов нет эквивалента «полный контекст репо» под узкую таксономию антипаттернов. |
| **P95 ≤ 10 с** как целевой SLA MVP | У выбранных аналогов в коммуникации — минуты; это конкурентное преимущество при сохранении качества. |

### Незакрытые боли конкурентов → ответ PRism

| Боль | Ответ PRism |
|------|--------------|
| Шум первых недель (CodeRabbit) | Порог confidence **per class** с первого дня. |
| Нет «архитектурного» слоя | Специализированный классификатор + RAG. |
| Цена Snyk для малой команды | Узкий scope и ценовая полка ближе Codacy/CodeRabbit (гипотеза в 3.8). |
| Непрозрачный FP (Codacy) | Confidence в inline-комментарии для разработчика. |

| Параметр | CodeRabbit | Codacy | Snyk Code | **PRism (цель)** |

## 3.8 Стандарты и цели PRism (кратко)

**MVP-требования:** webhook `pull_request`, inline review, объяснение + совет, threshold по confidence, **Java**, онбординг ≤ 10 мин, zero-training policy в доке, P95 ≤ 10 с, error rate < 1%.

**Монетизация (гипотеза):** per seat как у CodeRabbit/Codacy; Team **~$19/dev/мес** (annual) — ниже полки CodeRabbit Pro при узком scope; Free/OSS для роста.

**Целевые метрики против бенчмарка:** helpful rate ≥ 40%; FP ≤ 20%; F1-macro ≥ 0,60 (MVP) / ≥ 0,72 (prod); стоимость токенов ≤ $0,05/PR — см. `02_prototype.md` и `01_business_understanding.md`.

---

## 3.9 Выводы

PRism попадает в **узкую нишу** между generalist PR-AI и security-SAST: архитектурные антипаттерны с явным confidence и планом на RAG. Главный риск рынка — **шум**; средние по конкурентам по времени и точности задают планку ожиданий, но PRism конкурирует за счёт **специализации и скорости**, а не за счёт «средней» цены (целевая полка ниже CodeRabbit Pro и существенно ниже Snyk Ignite при сопоставимом размере команды).

OSS free tier остаётся критичным каналом органического роста по аналогии с лидерами сегмента.
